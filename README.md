# رفیعی ادیتور — نسخه‌ی بومی (Native)

یک ادیتور ویدیوی واقعی اندروید با محیط شبیه InShot. دیگر WebView و مرورگر در کار نیست.

## چرا مشکلات قبلی حل می‌شود
- **هنگ در اسکرول**: همه‌ی صفحه‌ها View بومی هستند و تایم‌لاین با Canvas کشیده می‌شود.
- **مدت ویدیو غلط (۳ ثانیه)**: خروجی با Media3 Transformer و رمزگذار سخت‌افزاری ساخته می‌شود و مدت فایل دقیقاً برابر تایم‌لاین است. در پایان مدت واقعی فایل نشان داده می‌شود.
- **پخش بند بند**: دیگر ضبط Canvas با MediaRecorder نداریم؛ ویدیو H.264 + AAC استاندارد با نرخ فریم ثابت است.

## ساخت APK با GitHub Actions
1. پوشه را در یک مخزن GitHub آپلود کنید (همین ساختار، شامل `.github` و `rafiei.jks`).
2. به تب **Actions** بروید و workflow به نام Build را اجرا کنید (یا با push خودکار اجرا می‌شود).
3. پس از پایان، APK را از بخش **Artifacts** دانلود کنید.
کلید امضا در مخزن است، پس هر نسخه‌ی جدید روی نسخه‌ی قبلی نصب می‌شود.

## بخش‌ها
- صفحه اصلی: ویدیو / عکس / کولاژ، تازه‌ها، پیش‌نویس‌ها (جدید، تغییر نام، کپی، حذف)، تنظیم زبان فارسی/English.
- ویرایشگر: بوم (نسبت و پس‌زمینه)، صدا (موسیقی، افکت صوتی، ضبط، گفتار متن)، استیکر، متن، افکت، فیلتر، عکس روی ویدیو، برش، تقسیم، کپی، حذف، سرعت، فریز، چرخش، انیمیشن ورود/خروج، انتقال بین کلیپ‌ها، حجم صدا، حذف/جداسازی صدا، Undo/Redo.
- خروجی: ۴۸۰p تا 4K، چهار سطح کیفیت، پیشرفت، لغو، ذخیره در گالری، اشتراک.
- کولاژ: چیدمان برای ۲ تا ۶ عکس، جابه‌جایی و زوم هر خانه، فاصله، گردی، رنگ پس‌زمینه.

## نکته‌ی مهم
این نسخه در محیطی بدون اینترنت نوشته شد و **کامپایل نشده است**. اگر در اولین build خطایی دیدید، متن خطا را بفرستید تا اصلاح شود. اگر خروجی در دستگاهی خطا داد، دکمه‌ی «تلاش دوباره (حالت ایمن)» افکت‌های سنگین را خاموش می‌کند.

## ابزارهای بخش ۱، ۲ و ۳ (فایل HTML قبلی)
- **اکولایزر** (نوار ابزار اصلی): ۵۳ طرح، رنگ‌ها، میله‌ها، پس‌زمینه، عکس داخل قاب؛ واکنش به صدای واقعی (پیش‌نمایش و خروجی یکسان).
- **حرکت**: حدود ۲۵۰ پیش‌تنظیم حرکت عکس/ویدیو با شدت قابل تنظیم.
- **استودیو نور**: پرتو، فوکوس، نوار و اسپات.
- **زیرنویس**: زمان‌بندی خودکار، متن زمان‌دار/LRC، استایل.
- **PIP**: عکس روی ویدیو.
