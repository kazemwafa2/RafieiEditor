# رفیعی ادیتور (Rafiei Editor) — v2.1 (کد ۳)

ویرایشگر عکس/ویدیوی آفلاین اندروید: تایم‌لاین چندلایه، زیرنویس خودکار Whisper/Vosk، حذف پس‌زمینه، اکولایزر تصویری، و خروجی با Media3.

## ساخت APK

### ۱) در GitHub Actions (پیشنهادی)
1. مخزن را بسازید و این پروژه را push کنید (**بدون هیچ فایل کلیدی**).
2. برای امضای نسخهٔ انتشار، در `Settings → Secrets and variables → Actions` چهار مقدار اضافه کنید:
   - `KEYSTORE_BASE64` — خروجی این دستور روی فایل کلید شما: `base64 -w0 rafiei.jks`
   - `KEYSTORE_PASSWORD` — رمز keystore
   - `KEY_ALIAS` — نام مستعار کلید (مثلاً `rafiei`)
   - `KEY_PASSWORD` — رمز کلید
3. تب **Actions** → workflow `Build APK` را اجرا کنید (با push هم خودکار اجرا می‌شود) و APK را از **Artifacts** بگیرید.

اگر Secrets تنظیم نشده باشند، build به‌صورت خودکار با یک کلید آزمایشیِ فقط-CI امضا می‌شود و در خلاصهٔ اجرا هشدار می‌دهد — برای تست خوب است، برای انتشار نه.

### ۲) ساخت محلی
```bash
# keystore.properties کنار build.gradle اصلی (ریشه) بسازید:
# storeFile=/absolute/path/to/rafiei.jks
# storePassword=...
# keyAlias=rafiei
# keyPassword=...
gradle assembleRelease        # یا: ./gradlew اگر wrapper jar را regenerate کرده باشید
gradle assembleRelease -PnoWhisper   # بدون موتور whisper (فقط Vosk)
```

هیچ کلید یا رمزی در این مخزن نیست؛ `keystore.properties` و `*.jks` در `.gitignore` هستند.

## نکته‌های مهم
- workflow فونت‌های فارسی/عربی (SIL OFL) و مدل Vosk فارسی را **در زمان build** دانلود می‌کند تا مخزن سبک بماند.
- whisper.cpp از سورس داخل `app/src/main/cpp` ساخته می‌شود (CMake 3.22.1). اگر ساخت native شکست خورد، workflow خودکار با `-PnoWhisper` ادامه می‌دهد و برنامه فقط از Vosk استفاده می‌کند.
- وضعیت کامل امکانات با چهار وضعیت صادقانه: `FEATURES.md` — فهرست تغییرات این نسخه: `CHANGES.md`.
- تمام پردازش هوش مصنوعی روی خود گوشی است؛ هیچ رسانه‌ای به سرور فرستاده نمی‌شود.

## بخش‌های اصلی
- خانه: پروژهٔ ویدیو/عکس/کولاژ، پیش‌نویس‌ها (باز/نام/کپی/حذف)، پشتیبان‌گیری ZIP، بانک زبان، دو زبانه (فارسی/English).
- ویرایشگر: بوم، صدا (موسیقی/افکت/ضبط/TTS)، استیکر، متن، افکت، فیلتر + پیش‌تنظیم شخصی، تنظیم ۹گانه، برش/زوم، معکوس (ویدیو+صدا)، فریز، سرعت و Ramp، کی‌فریم، موشن، نور، ماسک، حذف پس‌زمینه، زیرنویس خودکار + ترجمه، SRT/VTT/ASS، Beat-sync، Undo/Redo، گام فریم.
- خروجی: ۴۸۰p تا 4K، ۴ سطح کیفیت، قالب شبکهٔ اجتماعی، Wake lock، لغو امن، حالت ایمن، ذخیرهٔ گالری.

## مخزن گیت‌هاب و به‌روزرسانی‌یاب
- بعد از push کردن پروژه، آدرس مخزن را در `app/src/main/assets/repo.txt` بنویسید (یک خط: `owner/repository`) و دوباره منتشر کنید.
- برای اینکه «بررسی به‌روزرسانی» داخل برنامه کار کند: در GitHub یک **Release** بسازید، توضیحات Release همان تغییرات نسخه (changelog) می‌شود و یک فایل `.apk` به آن پیوست کنید. برنامه نسخه، تاریخ و تغییرات را نشان می‌دهد، با نوار پیشرفت دانلود می‌کند، سلامت فایل و تطبیق امضای دیجیتال را بررسی می‌کند و بعد از تأیید شما نصب می‌کند (داده‌های پروژه‌ها حفظ می‌شود).
- دکمه‌های تماس (واتساپ `+93 770 230 338` و فیس‌بوک) در مسیر «تنظیمات ← درباره ما و تماس با ما» هستند.
